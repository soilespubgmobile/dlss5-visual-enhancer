# Relios Vision – Visual Enhancer v22.0 üzerine kurulum paketi

Program kapalıyken bu zip'in içindekileri program klasörüne kopyalayın ve
"Dosyaların yerini değiştir" deyin. Önce program klasörünün yedeğini alın.

- Arayüz Türkçe açılır (ilk açılışta otomatik). Dil listesinde yalnızca Türkçe ve English var.
- Ayarlarım menüsü: "Kayıtlı ayarlarım…" penceresinde Ayarım 1–5 (Kaydet / Yükle),
  ayrıca "Dosyadan aç…" ve "Dosyaya kaydet…". Yuvalar program klasöründeki "ayarlar" klasöründe durur.
- Relios renkleri ve simgesi, "Relios Vision" adı, Hakkında yok, Modeller'de yalnızca durum.
- Qt6Network.dll: ağsız; program internete çıkmaz.
