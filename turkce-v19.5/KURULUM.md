# Visual Enhancer v19.5 için Türkçe

Hazır v19.5 programı Türkçeyi dil listesinde tanımıyor. Bu yüzden Türkçe çeviri, Lehçe (Polski) dosyasının yerine konur.

1. Visual Enhancer kapalıyken program klasöründe `resources\desktop\translations` klasörünü açın.
2. Oradaki `app_pl.qm` dosyasının adını `app_pl.qm.yedek` yapın.
3. Bu klasördeki `app_tr_v19.5.qm` dosyasını oraya kopyalayın ve adını `app_pl.qm` yapın.
4. Programı açın: Settings → Interface Language → **Polski** seçin. Arayüz Türkçe olur.

Geri almak için `app_pl.qm` dosyasını silin ve `app_pl.qm.yedek` dosyasının adını tekrar `app_pl.qm` yapın.

`app_tr_v19.5.ts` çevirinin düzenlenebilir kaynağıdır (1239 metin).
